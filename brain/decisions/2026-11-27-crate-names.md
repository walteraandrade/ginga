# Crate names: `ginga` and `ginga-gpui`

**Chosen.** The engine is `ginga` and the GPUI adapter is `ginga-gpui`. Issue #2, pull requests #16 and #53.

**Options.** Waltinho first let an agent choose the names; the alternative was a new name if either was taken. On 2026-11-27 he was shown three other pairs, all free then (`molejo`, `balanco` and `frevo`, each with `-gpui`), and kept these.

**Why.** Both names were free on crates.io on 2026-11-27, checked against a crate that exists so that an empty answer meant free. The adapter is named after the engine plus the framework, so another adapter would follow the same pattern.
